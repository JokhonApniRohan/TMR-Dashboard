TMR Tracking Dashboard - Project Notes
=====================================

1. Project purpose
-----------------
This dashboard is designed for TMR (Trade Market Representative) field operations tracking.
It helps review:
- Attendance
- KPI performance
- Daily activity and summary reports
- TMR-wise performance
- Date range and region-based filtering

2. Main pages
-------------
- index.html : Main dashboard overview
- attendance.html : Attendance view with filters and performance summary
- kpi.html : KPI view with metric cards and charts
- tmr-report.html : TMR detail report page
- upload.html : Excel upload and processing page

7. Attendance calculation logic
-------------------------------
Attendance is planned to be calculated using these rules:

Attendance Criteria (70% of total salary)
1. Visit target achievement must be at least 75% of the daily unique visit target.
2. The visit must be completed within official business hours: 10:00 AM to 7:00 PM.
3. Each visit duration must be at least 3 minutes and not more than 10 minutes.
4. Friday, government holiday, and paid leave entries will be treated as paid leave in the attendance logic. These values are expected to be numeric counts in the report sheet.
5. Targets will be read from the uploaded sheet files rather than hardcoded in the UI.

Suggested attendance output fields:
- Present / Absent
- Attendance %
- Payable Day
- Approved Leave
- Market Hour Achievement
- Strike Rate Achievement
- Daily visit target
- Monthly agent coverage target

8. KPI calculation logic
------------------------
KPI is planned to be weighted as follows:

A. Market Hour
- Evaluation period: Monthly average
- Target: 7 hours per working day
- Weight: 25%
- Calculation:
  - If actual average market hours are less than target, score = 0
  - If actual average exceeds target, score = actual hours / target hours

B. Strike Rate
- Evaluation period: Daily average
- Target:
  - 30 for Non-Metro
  - 35 for DN/DS/CTG Metro
  - 40 for Other Metro
- Weight: 35%
- Calculation:
  - Actual visit count / target visit count

C. Frequency-wise Achievement
- Evaluation period: Weekly average
- Target:
  - 180 for Non-Metro
  - 210 for DN/DS/CTG Metro
  - 240 for Other Metro
- Weight: 40%
- Calculation:
  - Actual visit count / target visit count
